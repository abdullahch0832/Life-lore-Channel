# YouTube Description Template

> Modeled on RealLifeLore's own descriptions (credits + sources + sponsor + links).
> Keep it clean; this niche does not rank on tags, so put the effort into a clear,
> credible description and a pinned sources comment.

```
[One or two sentence hook that restates the paradox and teases the answer.]

🔔 Subscribe: https://www.youtube.com/@YOURCHANNEL?sub_confirmation=1

— SPONSOR —
This video is sponsored by [Sponsor]. [1–2 line pitch + your link/code.]

— CHAPTERS —
0:00  The paradox
0:30  [Beat 3 label]
0:00  [Beat 5 label]
0:00  The geography
0:00  The history
0:00  What happens next

— SOURCES —
• [Source 1 — title + link]
• [Source 2 — title + link]
• [Source 3 — title + link]
(Full source list pinned in the comments.)

— CREDITS —
Maps: MapTiler / OpenStreetMap contributors, GEOlayers 3
Select footage courtesy of [Getty Images / AP Archive / Storyblocks / Pexels]
Music: [track + license]

— FOLLOW —
[Socials]

#geography #geopolitics #[country]
```

## Rules
- **Chapters** help retention + the algorithm understand the arc — always include them.
- **Pin a comment with full sources.** It builds trust and preempts "correction" comments.
- Credit all map tools + footage libraries (license compliance).
- 3–6 relevant hashtags max; brand‑level tags only (per `docs/01`).
